## Randomized verification

Seeds 0–999 use ChaCha8. Every trace is generated twice to check determinism and
round-tripped through EventLog v0. Bounds are asserted: <=6 logicals, <=14 revisions,
<=10 rules, 1–3 supporting premises on accepted rules, <=12 batches, 1–5 Ops per
batch. Kinds include Evidence and Summary. Raw edge selection is Pin 40%, Cur 25%,
Sem 20%, Ref 15%. Errors, Rebind, validation, head/base and enable operations occur.

Every accepted/rejected transaction checks I1 input equality, full error equivalence,
full Jacobi/Kahn snapshot equality (PROP8), L2 subset L1 subset L0, rollback, snapshot
codec round trips, and exact l0_flips/status_diff sets. Failure traces are exported
under ignored `results/` for reproduction. No failures needed shrinking.

## Limits and next phase

P0 is an in-memory oracle-backed Rust API, MAIN-only and single subject. It has no
incremental counting, durable acknowledgements, full certificate issuance, daemon,
MCP server, filesystem observer, multi-branch isolation, ACL or erasure. Conflict
is None; synthetic future summary dimensions are pure-function tests only.

No performance claim is made. After the remaining formal CI evidence is available,
P1 can implement the Maintainer facade, counting, Pearce–Kelly, exact-mode regression,
coverage thresholds, exhaustive/mutation checks and specified performance budgets.
