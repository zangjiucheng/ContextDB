# Gate P6 — Versioned transactions, branches and WHAT_IF

Status: **G0 passed (2026-10-23); implementation done. G1, G2, G3, G4, G5, G7 and G8 pass (2026-10-26). The independent review remains.**

Implementation milestones:

1. Read sets (`ExpectHeads`) in the single-branch engine and the oracle: done.
2. Multi-branch kernel: branch table, fork, commit routing, global ids and
   key namespace (ADR §3.1): done.
3. Visibility and cross-branch dedup imports (contract 5, ADR §11a):
   done.
4. WHAT_IF and `IMPACT{Exact}` on an undo journal (ADR §5), in the
   database and the kernel: done.
5. Merge: sync points, merge base by containment, three-way
   classification, Conflict artifacts, cycle recheck, certification, read
   sets, observer domain and `anchor_unobserved` (ADR §6.3a): done.
6. Conflict gate in the kernel and the oracle (ADR §6.4): done.
7. Independent branch oracle and PROP13 at 10,000 seeds (ADR §11): done.
   It found two defects, now fixed: the canonical order on branches and A5
   on merges (ADR r0.5).
8. Store format 3: the kernel in the store, the result trailer, kernel
   snapshots, migration 2→3 with changed results reported, branch-keyed
   projections (schema 2), EventLog v1 (ADR §8): done.
9. Protocol 4:
   - 9a, branch-aware reads with global ids, `BRANCH_ONLY` (S13),
     per-branch certificates and `BranchMismatch` (T62): done.
   - 9b, sessions and the observer on branches (protocol 4 session and
     anchor fields, D1 resolution, durable binding): done.
   - 9c, protocol 4 requests (Commit with expect_cert_valid, WhatIf,
     Branch*, Merge, OnBranch), MCP tools, CLI commands and hook claims:
     done.
   - 9d, the remaining end-to-end checks (below): done.
10. Gate runs (G1, G3 mutation, G4, G5, G7, G8): done (below). They found
    four defects, all fixed: the branch oracle depended on blake3 (G1), and
    G4's branch stress found a cubic merge-base search and sync points that
    retained whole databases (ADR r0.6).


[ADR 0013](../adr/0013-p6-branches-transactions.md) r0.4 was accepted after:

- an independent review (4 blockers, 12 majors, 6 minors);
- a closure check (4 new majors);
- a re-check (R1–R4);
- a final check.

SPEC v1.6.8 mirrors it. Owner decisions:

- **D1:** branches are created explicitly; a session binds to the branch
  named like its git branch, otherwise `main`.
- **D2:** agents may merge, including into `main`; `require_certified`
  defaults to true.
- **D3:** the SD17 Conflict gate moves into P6.

P6 depends on P5b (SPEC §5). P5b's gate in turn waits on P5a and P4
(A11), so P6's gate cannot pass before them. Implementation may proceed
meanwhile. The live dogfood stores (protocol 3, op_log format 2) are
upgraded only after the P4 dogfood report (≥ 2026-11-04).

## Scope

SPEC SD19 and its v1.6.8 supplement, SD17 (the P6 gate), SD13, SD14b
(`anchor_unobserved`), §5 P6, §6.1 contracts 12–13, §6.2–§6.4 and §7.
Out of scope: branch deletion, automatic git-merge detection, P7 conflict
producers, ACLs.
