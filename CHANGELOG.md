- Establish the Rust 1.95.0 workspace with 13 product/verification crate boundaries and an isolated R2 baseline workspace.
- Add the bootstrap `ctx --help` / `--version` commands; database commands remain unimplemented.
- Add Linux/macOS CI, license checks, dependency policy checks, and negative tests for the architecture gate.
- Implement P0 model contracts, immutable inputs, complete Op/error types, canonical wire and versioned EventLog v0.
- Implement independent InputModel staging/validation and Jacobi/Kahn full recomputation, three-layer certification, summaries and explanations.
- Implement core SoA/CSR arenas, indexes, independent canonicalization/CAS/cycle validation, rollback, NetDelta and both diff sets, with oracle-backed queries.
- Add 26 golden groups, three wire tests, policy hash golden, compile-fail API checks and 1,000 ChaCha8 seeds / 12,000 transaction comparisons.
- Record SPEC v1.4.1 executable details in ADR 0003, semantics traceability and P0 verification/review evidence. Local checks, independent review and remote Linux/macOS CI passed; P0 Gate is complete.
- Implement the P1 incremental counting kernel (Counting/FullRecompute, Pearce–Kelly, WHY/WHY_NOT, IMPACT, DIFF, shapes, bench).
- Compact P1 storage without semantic change: dense u32 PK, deduplicated indexes, CSR rule/logical arenas, post-state-only history. Live heap is 181–189 B/incidence (previous lower bound 292–314).
- Calibrate the P1 memory budget per scope (ADR 0005, SPEC v1.4.2). The bench measures live heap with a counting allocator and exits non-zero on failure. An allocator-checked accounting test is added. The mutation audit is extended to arena/memory with 0 survivors.
- Fix the nightly mutation job (missing `results/` directory). Propose the P2 durable op_log ADR 0006.
- Accept ADR 0006 and SPEC v1.4.3. Implement `contextdb-store`:
  - own segmented op_log with a blake3 hash chain and durable decoding limits;
  - ordered commit (idempotency, blobs, append + sync, publish) with fail-stop poisoning and a directory lock;
  - blobs, snapshots, replay and a sampled oracle self-check at open;
  - SQLite projections with a watermark;
  - Historical / Snapshot / DIFF read modes;
  - format-0 migration and doctor truncation;
  - a SimDisk crash-injection harness.
- Make structural commits incremental (ADR 0007): staging overlay, appendable CSR adjacency, open-addressing key table, Pearce–Kelly undo journal, incremental A5 and status walker. Cold replay of 100K structural transactions goes from O(N²) to about 1 s.
- Add `ctx replay | doctor | snapshot | migrate | export`.
- Add G4 crash injection at the blob-put and projection-write steps.
- Add mutation tests for the key table, adjacency and staging overlay; bound key-table probes.
- Shard the nightly mutation audit and add the P2 durability job.
- Fix the findings of the independent P2 review:
  - **Blocker:** a corrupt header on the final segment no longer deletes acked frames.
  - **Doctor:** truncation plans list every dropped frame.
  - **Migration:** an interrupted migration is refused at open and resumed by `migrate`.
  - **Locking:** offline tools take the store lock.
  - **Poisoning:** poisoned stores serve nothing, and poison is keyed per store directory.
  - **Reads:** frames are read by range.
  - **Tail handling:** semantic tail faults fail closed.
  - **Snapshots:** an unbuildable snapshot is ignored.
  - **`ctx`:** never creates a store.
  - **G4:** a real post-sync-pre-publish hook; small-segment runs exercise rollover.
  - **Bench:** gates the file-projection configuration; projection roll-forward is batched.
- Close the P2 closure-check findings:
  - projection writes use cached statements, and bulk roll-forward writes the watermark once (first open with file projections 0.55–0.61 s, previously up to 6.1 s);
  - roll-forward commits after the self-check;
  - catch-up is bulked and rolls back on failure;
  - open locks before creating `log/`;
  - `migrate` resumes from the newest backup and syncs before the swap;
  - `get_blob` is gated on poison.
- Close the P2 gate: independent review and two closure checks, CI run 39497969575 and nightly run 39498455621 on `de80aa6`.
- Accept P3 G0: ADR 0008 (daemon, group commit, session log, certificates, MCP) after four review rounds; SPEC v1.5.0–v1.5.3.
- P3 milestone 1 (core):
  - **Counter-based L1/L2 columns.** Per-incidence literal bits, per-rule counters and per-node truth, witness and reason replace the query-time memo. They are maintained by the rank-ordered status walker (SPEC §3.4 Phase 3b), and FullRecompute rebuilds them independently. `Db` is `Send + Sync`.
  - **Certificates.** `issue_certificate` and `validate_certificate` cover the L2-witness closure, `since_epoch` strict windows from a per-epoch change log, log linkage and recertification. The oracle gains an independent issuance and validation; PROP11 runs 10,000 seeds.
  - **Tests.** P3 engine goldens T06d-sem, T16, T16b-cert, T21, T62-P3 and T65. New PROP2b coverage gates.
  - **Memory.** ADR 0009 (owner decision) moves the L1/L2 state from the query-cache scope to the hot scope: hot ≤ 90, query cache ≤ 32 B/inc. The total is unchanged.
- P3 milestone 2 (store):
  - **op_log format 2:** group framing `{seq, idx, count}`, with migrations from formats 0 and 1.
  - **Recovery:** one tail algorithm, shared by op_log and the session log. Only the last group is truncatable, and semantic faults fail closed.
  - **`Store::commit_group`:** one sync per group, replies held until it, idempotency across ids staged in the group.
  - **Session log** (`sessions/`).
  - **`LogReader`** for reader threads.
  - **`watermark_history` projection.**
  - **Doctor:** cuts at group boundaries.
